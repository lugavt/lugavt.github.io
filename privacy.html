Política de privacidade

Última atualização: 3 de outubro de 2026.

Quem usa

O Wellness Coach é um projeto pessoal usado apenas pelo seu autor. Não há outros usuários.

Quais dados são acessados

Com permissão somente de leitura, o app acessa na Google Health API os dados de saúde do autor: sono, atividade e exercícios, frequência cardíaca, variabilidade da frequência cardíaca, peso, composição corporal, nutrição e informações dos dispositivos pareados.

Como os dados são usados

Os dados são usados exclusivamente para gerar planos de treino, resumos de sono e acompanhamento de hábitos para o próprio autor, em conversas privadas num bot do Telegram. Para escrever as respostas, trechos desses dados são enviados à API de um modelo de linguagem (Anthropic), apenas no momento de cada resposta.

Armazenamento

Os dados ficam num banco de dados no projeto do Google Cloud do próprio autor, com acesso restrito à conta do autor. Nada é vendido, compartilhado com terceiros para publicidade ou usado para treinar modelos de IA.

Uso limitado

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. O autor pode apagar os dados armazenados a qualquer momento.
